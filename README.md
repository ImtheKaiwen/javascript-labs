# JavaScript Labs

A collection of small browser-based JavaScript exercises. The examples use Turkish prompts and focus on introductory language features, user input, conditions, loops, arrays, and basic calculations.

## Exercises

| Directory | Exercise |
| --- | --- |
| [`giriş/`](<giriş/>) | Variables, loops, functions, console output, and comments |
| [`-+/`](<-+/>) | Positive, negative, or zero check |
| [`asalmı/`](<asalmı/>) | Prime-number check |
| [`Büyük küçük/`](<Büyük küçük/>) | Minimum and maximum values from user input |
| [`faktoriyel/`](<faktoriyel/>) | Factorial calculation |
| [`metinde ara/`](<metinde ara/>) | Character counting in text |
| [`Dikdörtgen/`](<Dikdörtgen/>) | Rectangle area and perimeter |
| [`daire  alan/`](<daire  alan/>) | Circle area and circumference |
| [`hipotenüs/`](<hipotenüs/>) | Hypotenuse calculation |
| [`Beden kitle/`](<Beden kitle/>) | Body mass index exercise |
| [`Not Programı/`](<Not Programı/>) | Grade pass/fail check |
| [`bacground/`](<bacground/>) | Early background-color exercise stub |

## Run an exercise

Open the `.htm` or `.html` file inside an exercise directory in a browser. Most examples request input with browser prompts and show results with alerts, the page, or the developer console.

For example, open [`faktoriyel/htm.htm`](<faktoriyel/htm.htm>) to run the factorial exercise.

## Scope

These are independent learning snippets rather than a single application. Directory and file names have been preserved to retain the original exercise history. The `bacground` example currently contains comments only and does not yet change the page.
